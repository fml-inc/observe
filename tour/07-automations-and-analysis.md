Two ways FML works while you're not looking:

**Automations** — scheduled or event-triggered agents, managed in the dashboard: a daily digest of yesterday's engineering activity, or a watcher that fires when a deploy event arrives.

**Analysis workflows** — deep codebase analyses across security, architecture, performance, and code quality. Results stay searchable, so "what did the last security analysis flag?" is answerable in conversation later.

```
fml automation list
fml_run_analysis_workflow / fml_search_analysis
```
